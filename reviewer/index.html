Reproduce the recorded experiment

git clone --branch reviewer-demo https://github.com/AviSrikumeran/syncode-bibtex.git
cd syncode-bibtex
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.venv\Scripts\python.exe run_tests.py
.venv\Scripts\python.exe bibtex_syncode.py --compare --trace-steps 8 --revision 7ae557604adf67be50417f59c2c2f167def9a775 --output results/reproduction.json
.venv\Scripts\python.exe review_demo.py

Windows / Python 3.12 is the verified environment. On macOS/Linux, use python3.12 and .venv/bin/python; those platforms have not been verified here. The model downloads about 1 GB the first time. Windows may require Microsoft's Visual C++ x64 runtime.

What a reviewer should challenge

  • Does accepting the seven assignment examples also reject malformed syntax?
  • Does the comparison measure raw output format, extracted citation syntax, or factual correctness?
  • Can the model finish before its token limit? Can the selected grammar mode block otherwise useful tokens?
  • Does the experiment generalize beyond three prompts? This run alone does not establish that.
